## ▶️ How to Run

**C**
```bash
gcc filename.c -o output
./output
```

**C++**
```bash
g++ filename.cpp -o output
./output
```

**Java**
```bash
javac FileName.java
java FileName
```

> On Windows, run `output` instead of `./output`.
